# Community Ports

DSPy has inspired implementations across many programming languages. These community-maintained ports bring DSPy's programming paradigm to different ecosystems.

If you have created a DSPy port in another language, please submit a PR to add it here!

## Language Implementations

| **Language**   | **Project**                                           | **Stars** | **Description**                              |
| -------------- | ----------------------------------------------------- | --------- | -------------------------------------------- |
| **Clojure**    | [DSCloj](https://github.com/unravel-team/DSCloj)      |           | Inspired by DSPy, adapts concepts to Clojure |
| **Elixir**     | [dspy.ex](https://github.com/arthurcolle/dspy.ex)     |           | Inspired by DSPy, adapts for Elixir          |
| **Go**         | [dspy-go](https://github.com/XiaoConstantine/dspy-go) |           | Native Go implementation                     |
| **.NET**       | [DSpyNet](https://github.com/al322se/DSpyNet)         |           | C# .NET port                                 |
| **R**          | [dsprrr](https://github.com/jameshwade/dsprrr)        |           | R implementation inspired by DSPy            |
| **Ruby**       | [dspy.rb](https://github.com/vicentereig/dspy.rb)     |           | Ruby port                                    |
| **Rust**       | [DSRs](https://github.com/krypticmouse/DSRs)          |           | Ground-up Rust rewrite                       |
| **TypeScript** | [ax](https://github.com/ax-llm/ax)                    |           | Inspired by DSPy for TypeScript              |
| **TypeScript** | [dspy.ts](https://github.com/ruvnet/dspy.ts)          |           | Complete TypeScript implementation           |

## Notes

These are community-maintained projects and are not officially supported by the DSPy team. Feature availability and API compatibility may vary.
